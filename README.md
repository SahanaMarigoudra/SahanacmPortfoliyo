## ✨ Key Features

This portfolio is built with a focus on high-quality aesthetics, responsiveness, and clean interactive elements:

*   **Immersive Animated Background**: Custom ramer-motion ambient glowing orbs over an architectural tech-grid overlay.
*   **Modern Project Viewers**: High quality, glassmorphic project cards featuring interactive image carousels and sleek styling.
*   **Sleek Minimalist Typography & Layout**: Carefully weighted typography, subtle frosted glass containers, smooth hover interactions, and an uncluttered layout to provide a premium user experience.

*   **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)

## Security

- No secrets should be committed to this repository.
- Local environment variables should be stored in .env files.
- Real .env files are excluded through .gitignore.
- Frontend NEXT_PUBLIC_* variables are public and must not contain private secrets.
- Private API credentials must remain server-side.
- Dependency security should be checked regularly.
